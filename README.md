# Portafolio de Economía y Datos

Colección de proyectos de análisis económico aplicado, con enfoque en 
investigación de mercados nicaragüenses.

## Sobre mí
Estudiante de economía interesado en análisis de datos, econometría 
aplicada y automatización de procesos con Python.

## Proyectos

### 📊 Elasticidad de Demanda - Matagalpa
Herramienta interactiva para análisis de elasticidad de demanda con 
encuestas de consumidores. Desarrollada en React/Tailwind.

### 🐍 Bootstrap Estadístico en Python
Scripts para estimación de elasticidad mediante remuestreo bootstrap, 
aplicados a datos de encuestas de campo.

## Tecnologías
- Python (numpy, scipy, pandas)
- React / Tailwind CSS
- Métodos estadísticos: bootstrap, MCO, elasticidad
